🚧 왜 바꿨는가 (마주친 한계) "두꺼비집 내려가" 같은 일상어는 한자어 학술 색인을 못 찾고, 반대로 타이핑마다 LLM 번역기를 부르자 단일 슬롯 GPU에 오타 조각이 쌓여 89.7초 지연과 캐시 오염이 발생했습니다.

📈 무엇이 달라졌는가 (실증 지표) 타이핑 중 GPU 호출 0회 · 구어체 검색 적중 10/10 · 실측 질의응답 대기 시간 89.70초 → 22.66초 단축.
STAGE 6 · 신경-기호 추론 외골격 'Adaptive Thinking' 제어 & '139종 L3 파이썬 기호 외골격(2-Pass 자율 계산)' 연동
🚧 왜 바꿨는가 (마주친 한계) 로컬 14B의 복합 수리 추론 한계를 넘어야 했고, 무조건 <think>를 켜면 단순 조회까지 느려지며 끄면 다단계 수식에서 실수가 발생했습니다.
🛠️ 어떻게 해결했는가 (설계 전환) 질문 난이도별 Adaptive Thinking과 139종 vault_stdlib.py 2-Pass 자율 계산(변수 JSON 추출 → 파이썬 실행 → 해설 합성)을 결합했습니다.
📈 무엇이 달라졌는가 (실증 지표) 내장 결정론적 검증 함수 29종 → 139종 확장 · 복합 법령/재무/공학 수식 계산 오차 0.0% 유지.

4. 엔지니어링 진화 과정 9부작 전문 (탭을 클릭하여 열람)

[1부] 왜 '그냥 쓰는 클라우드 LLM'과 '원터치 로컬 LLM(Ollama 기본 설치)'은 실무 의사결정에서 실패하는가?
